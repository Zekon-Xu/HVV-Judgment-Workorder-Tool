# 工单处理工具

Windows 单文件桌面工具。支持文本、CSV/TSV、JSON、XML、Excel、HTML/MHTML 本地离线解析；配置在线 AI 后可研判文字并识别图片。工具只生成工单和处置建议，不执行封禁、隔离或下发动作。

## 使用

- 源码运行：`run.bat` 或 `python main.py`
- 重新打包：`build_exe.bat`
- 最终发布：`release_clean\工单生成工具.exe`

首次启动只在 EXE 旁生成 `settings` 运行目录；历史缓存、白名单、项目配置和模板均归档在该目录内。仓库和发布版均为纯白板：无客户数据、无项目配置、无 API Key、无历史记录、无本地文件路径、无 Logo、无白名单和公司网段。

`settings/templates/file_format_examples` 提供 TXT、CSV、JSON、XML、HTML 和 Excel 文件的规范示例，可直接作为待解析文件的格式参考；该目录与工具自身的模板配置分开。

## 工作流

- 单条：载入或粘贴材料，选择自动/本地/在线 AI，生成并复制工单。
- 批量：对未完成条目批量生成，并一次复制全部结果，不写 Markdown 或图片附件。
- 模板：首启为“自定义手动模板”。可逐项输入字段名和值；每一行可上移、下移或删除，也可拖动字段标签到目标行重新排序。自动导入的模板同样支持这些编辑操作。字段变化会立即生成本地提取规则、可识别的安全字段映射与 AI 提示词。
- 白名单：所有规则均可添加、删除；支持从文件增量导入、AI 提取、备份为 JSON，以及从 JSON 覆盖回滚。
- 历史：选择 Excel 后解析更新；在线同步需显式启用并保存。
- 离线兜底：处理 TXT/MD/LOG/CSV/TSV/JSON/XML/Excel、HTML/MHTML；图片必须使用在线多模态 AI。AI 提取失败时会显示明确原因后再回落本地。
- 微步情报：仅在工单生成后由用户手动确认查询，不参与 AI 研判或自动生成工单。

API Key 保存时使用当前 Windows 用户的 DPAPI 加密。复制 EXE 到其它 Windows 设备即可运行，用户配置不会被打包进 EXE。
